# GestorTareas | Simulacro de aplicación de gestión de tareas con recordatorios.

El usuario se registra con un correo y una contraseña, y ya puede crear una lista de tareas, crear tareas con distinta prioridad, añadir la fecha del recordatorio y publicarla.

El usuario va a poder crear, modificar, borrar y leer tareas, ordenar por orden de prioridad, cambiar su prioridad, cerrarlas o incluso borrarlas si deseara.
